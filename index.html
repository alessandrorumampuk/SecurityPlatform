Bagi Direktur Utama, itu urusan staf teknis. Yang membuat mereka tidak bisa tidur adalah angka: berapa data, berapa rupiah, berapa besar reputasi yang dipertaruhkan.

ARSITEKTUR

Tiga tahap: fakta → relasi → bahasa manusia.

01

Context Ingestion

Pemindaian pasif satu kali muat: elemen UI, parameter, tautan, header, cookie, TLS, DNS — dinormalisasi menjadi graph objek bertipe dengan provenance (screenshot + bounding box).

Page · Element · Parameter · Endpoint · Domain · IP · Cookie · Cert
02

Impact Synthesis

Temuan adalah pola graph, bukan label: Input → flows_to → Endpoint → reflects → Page. Setiap edge menyimpan bukti, sehingga rantai serangan muncul sebagai traversal — dengan jalur, bukan tebakan.

Link→Domain(404) = verified BLH · Param(redirect)→external = Open Redirect chain
03

Executive Translator

Template: [Ancaman] + [Jumlah Aset] + [Dampak Bisnis]. Output layar utama bukan "HTTP 404" melainkan berapa data, rupiah, dan reputasi yang dipertaruhkan.

"Amankan 32 juta data nasabah Anda."

MENGAPA INI MENJUAL

Anda menjual asuransi, bukan alat.

Ketakutan yang terukur

"Anda kena SQL Injection" tidak berarti apa-apa bagi Direktur. "Anda akan kehilangan 32 juta data nasabah" langsung mengaktifkan manajemen risiko perusahaan.

Anti alert-fatigue

Scanner biasa menumpuk 10.000 peringatan Low/Medium. VVM menampilkan sedikit peringatan merah — semuanya dalam bahasa uang, data, dan reputasi.

Posisi setara konsultan

Bahasa output menempatkan VVM sejajar dengan laporan konsultan keamanan kelas McKinsey/KPMG — bukan scanner open-source gratisan. Direktur yang akan memaksa tim teknisnya memakainya.

"Direksi tidak membaca temuan teknis. Mereka membaca konsekuensi. VVM adalah satu-satunya layer translasi antara permukaan serangan dan ruang rapat."
